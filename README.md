# ORBIT MUSIC

一个面向个人使用的响应式音乐站。网页托管在 GitHub Pages，搜索、播放地址与歌词通过独立的公开 API 转发，不依赖阿里云。

## 当前能力

- 桌面、平板和手机响应式布局
- 酷我与网易云公开资源的真实聚合搜索
- 在线播放、进度、音量、上一首/下一首、循环
- 同步滚动歌词与译文开关
- 收藏、下载记录、本地音频导入和曲库管理
- 自定义歌单与浏览器本地持久化
- 服务端代理搜索、播放地址和 LRC 歌词接口，避免浏览器跨域
- 内置合成音频作为首页演示，不在本站存储第三方版权音乐

## 接入真实资源

首页示例数据位于 `dist/app.js`。用户执行搜索时，由 Worker 代理公开检索接口，并返回歌曲元数据、音频地址、封面、音质和 LRC 歌词。音频仍由原资源地址提供，本站不存储第三方音频文件。
